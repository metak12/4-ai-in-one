# AIProjects — Единое Android-приложение (4 в 1)

В этом проекте объединены все 4 приложения с вашей витрины **AIProjects**:
1. **Заметки Pro** (`ChatGPT`, `Python`, `SQLite`) — умный блокнот с автотегами, поиском по смыслу и генерацией summary.
2. **Telegram-бот помощник** (`Telegram API`, `GPT-4`, `Python`) — чат с LLM-ассистентом, менеджер задач/напоминаний и личный дневник с анализом настроения.
3. **Кулинарный помощник** (`GPT`, `Flask`, `PostgreSQL`) — подбор рецептов по проценту совпадения продуктов из холодильника + AI-генератор авторских блюд с КБЖУ.
4. **AI-подкаст студия** (`TTS`, `Whisper`, `FastAPI`) — генерация диалога двух ведущих из любой статьи, живая озвучка (Neural TTS + WebAudio визуализатор) и скачивание `.WAV`.

## Как получить готовый `.apk` файл за 2 минуты (3 способа)

### Способ 1: Автоматическая сборка APK в облаке GitHub (Без установки Android Studio!)
В проект уже встроен готовый сценарий облачной сборки `.github/workflows/build-apk.yml`:
1. Создайте бесплатный репозиторий на [GitHub](https://github.com/new) и загрузите туда файлы из этой папки.
2. Перейдите на вкладку **Actions** в вашем репозитории — сборка `Build AIProjects Android APK` запустится автоматически.
3. Через ~2 минуты нажмите на завершённый запуск и скачайте готовый установочный файл **`AIProjects-Hub-Android-APK` (`app-debug.apk`)** в разделе **Artifacts**.

### Способ 2: Сборка в Android Studio на компьютере
1. Откройте папку проекта в **Android Studio** (`File -> Open`).
2. Дождитесь завершения синхронизации Gradle.
3. Выберите в верхнем меню **Build -> Build Bundle(s) / APK(s) -> Build APK(s)**.
4. Готовый файл появится по пути `app/build/outputs/apk/debug/app-debug.apk`.

### Способ 3: Быстрая конвертация HTML в APK со смартфона
Полностью автономная версия приложения находится в файле `app/src/main/assets/index.html` (а также прикреплена отдельно как `aiprojects_hub.html`).
Вы можете:
- Открыть `aiprojects_hub.html` в браузере Chrome на Android и нажать **«Добавить на главный экран»** (приложение установится как полноэкранное PWA).
- Или загрузить `index.html` в любой бесплатный генератор WebView APK (например, *Website 2 APK Builder* или * Cordova/Capacitor*).
