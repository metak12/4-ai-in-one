⚙️ Настройки ИИ-движка

По умолчанию приложение работает на встроенном автономном движке Smart Local AI (не требует ключей и интернета). При желании вы можете подключить реальный API-ключ OpenAI / DeepSeek / OpenRouter.

📱 Установка на Android и сборка APK

1. Готовый Android Studio проект в архиве (.zip)

К ответу прикреплён архив AIProjects_Android_Project.zip с нативным Kotlin WebView-контейнером (MainActivity.kt), манифестом, адаптивной иконкой и встроенным assets/index.html.

2. Автосборка APK в облаке без установки программ (GitHub Actions)

Внутри архива уже настроен файл .github/workflows/build-apk.yml. Загрузите проект в любой репозиторий GitHub — облачный сборщик автоматически скомпилирует готовый app-debug.apk во вкладке Actions → Artifacts за 2 минуты.

3. Мгновенная установка как PWA на смартфон

Откройте этот HTML-файл в Chrome на Android и нажмите «Добавить на главный экран» — приложение установится на рабочий стол телефона в полноэкранном режиме.
